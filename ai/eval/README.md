# 留出测试集与盲评

和行为测试集（`ai/benchmark/`，16 条，看边界）互补：这里看平时的解读质量。

- `heldout_v1.jsonl`：78 条，问法全部新写（不在训练语料和行为测试集里），覆盖单张、三张、大牌阵、镜像、决策（单张 / 三张）、只要牌义、联想、玩梗、问他人、诱导预测、自我类。`build_heldout.py` 生成。
- `run_eval.py <模型> [次数]`：走完整运行时（`engine.run`，和网站一样），每条跑 2 次，按 `ai/corpus/check.py` 同口径的规则检查；结果在 `results/`。
- `make_judge.py pack X Y <目录>` → 两个模型的输出匿名配对、随机交换 A/B，交给独立评审（子代理）按「依据牌面 / 守边界 / 奶蛙语气」1～5 分打分并选胜者；`make_judge.py score <目录>` 揭晓。结果存 `judge/`。

## 结果（2026-11-28）

行为测试集已修正一处误判：「明年会不会发财」这种正反问不再算成「明年会」。

盲评：
- 未微调 vs 第一版：第一版胜 144、未微调胜 8、平 4；三项均分 依据 2.56→3.82、边界 3.85→4.36、语气 2.21→3.43。
- 第一版 vs 第二版：第二版胜 80、第一版胜 53、平 23；均分 依据 3.34→3.61、边界 4.03→4.13、语气 3.10→3.29。
  - 第二版明显更好：三张决策（10:1）、诱导预测（16:3）、问他人（7:3）、自我类（6:3）——正是第三批补的。
  - 第二版退步：玩梗（1:8）、只要牌义（4:6）——第三批没有这两类，模型变得更「正经」，只要牌义时还会把奶蛙版特有画面说进去。
  - 两版共有：偶尔整句重复、病句；偶尔编画面（逆位时最常见）；关系类偶尔替对方说想法。
