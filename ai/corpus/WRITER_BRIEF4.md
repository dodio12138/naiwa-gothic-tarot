# 写作说明（第四批起：知识问答、寓言、低语、压缩、渐进展开、多轮反馈）

先完整读 `ai/corpus/WRITER_BRIEF.md`（奶蛙的声音、硬规则、反面回答的写法），全部适用。全程简体中文；只读仓库，不改仓库文件，不做 git 操作；草稿只放在指令给你的子目录里。

输入 `batches4_*/batch_NNN.jsonl`，每行一条，字段同前：`messages` 是运行时真实发给模型的对话（多轮时含之前的对话），你写**最后一轮助手该说的话**。写法要求以 `messages` 最后一条里「这一轮你要做的」为准。
输出每行：`{"case_id": "...", "response": "...", "rejected": "...或 null", "error_type": "...或 null"}`。

## 各任务的写法

### 知识问答（task = explain_knowledge / explain_philosophy，动作 EXPLAIN）
- 只用提示词给出的资料：牌义、意象、**意象的传统读法**（每条标了出处：韦特原典 / 黄金黎明 / 通行读法）、对应（含星座所属的元素）、传统画面说明、韦特原典的占卜义（标了正位或逆位，英文原文，可以意译）、可借用的观点和它的「不适用」、牌里的张力（本站整理的解读）。
- **分清出处**：韦特原典怎么说、通行（现代）解读怎么说、对应体系（元素、星座、行星）。不要把对应体系说成「韦特原典」，不要把通行解读说成「原典」。资料里没有的说法（比如某张牌对应的希伯来字母，如果没给）就说「这里的资料没有提到」，不编。
- 意象问题：用「意象的传统读法」里那一条（说明出处），再落到这张牌在当前正逆位下的意思。资料里没有这个意象的读法时，说「这个细节传统上没有固定的读法」，再落回整张牌——**不要自己补常识**（小模型学了会乱编）。
- **韦特原典和今天的读法不一致时**（很常见，韦特自己也说占卜义是约定俗成的）：照实说，用固定的过渡：「韦特原典列的是……；今天通行的读法更偏……」，一句带过，不展开争论。
- 「张力」和「可以借用的观点」是本站整理的解读：说成「一种常见的读法」「这张牌常被这样理解」，不要说成原典。
- 站内牌义里偶尔有带预测口吻的句子（如「轮子总会再转上来」），不要照搬预测的部分。
- 两张牌的区别：只有一张牌有资料时，另一张只按牌名常识简短对比，不编另一张的画面细节。
- 哲学 / 张力问题：把两极都说清楚，说它们在什么情况下各自成立、什么时候不适用（用资料里的「不适用」），不宣称哪一边是真理，不说教。
- 不分析用户，不提问。80～200 字。

### 寓言（task = parable，动作 PARABLE）
- 100～200 字的小场景：用这张牌给出的意象（或奶蛙版画面）做道具，有一个转折；可以有一个旅人、一个守灯的人、一只狮子……但**不要把主角写成「你」，不给用户贴标签**。
- 用户带了处境（「最近工作很累，讲个故事」）时，故事可以呼应，但不点破、不说「就像你一样」。
- **结尾不说教、不总结道理**（不要「这告诉我们……」），可以停在画面上。不提问。
- 每条换一个场景和角色，不要都写成「从前有一个……」。
- 牌面意象是故事的核心；可以加少量日常道具（椅子、雨、旧外衣），但**不加别的牌的标志性画面**（狮身兽、天秤、镰刀、龙虾……），也不要哥特 / 暗夜意象（恶魔的蝠翼也不用）。
- **比方（action_reason = PARABLE:analogy，用户说「打个比方 / 用个比喻」）**：不讲故事，一两句、60～120 字：先说比方（一件日常的事或物），再用一句点出它和牌面哪个意象对应。

### 低语（task = whisper，动作 WHISPER）
- 一句，**24 字以内**，只借一个给出的意象；克制、留白；不说教、不预测；不用「你」开头；**不照抄、不轻改「已有的低语」**（写新的）。只输出这一句，不要引号。
- 带了用户问题时，可以轻轻呼应，但不点破、不给建议。

### 压缩（task = compress，动作 COMPRESS）
- 把给出的那段解读压成一句：单张 **30 字以内**；多张（action_reason = COMPRESS:multi）**45 字以内**，可以只保留整体的走向和最关键的一两个意象。**不加原文没有的内容**，不预测。只输出这一句。

### 渐进展开（task = expand，动作 EXPAND，多轮）
看 `action_reason`：
- `EXPAND:deeper`：往下展开一层：换一个上一轮没用过的意象，或从意象推到它背后的观点，或落到用户问题的具体情境；**不重复上一轮的句子**。80～180 字。
- `EXPAND:angle`：换一个角度（另一个意象、矛盾的另一极），不否定上一轮。80～180 字。
- `EXPAND:shorter`：一两句重说重点，40 字以内，不加新内容。
- `EXPAND:counterfactual`：「如果是逆位 / 正位呢」（用户问的方向一定和这张牌现在的方向相反；多张时用户会点名是哪一张）：依据牌义说清哪些意思会变、哪些不变；另一方向的牌义资料里没有，只按「正位顺畅、逆位受阻或过度」这类一般规律简短说，不编画面、不编具体牌义。80～160 字。
- 都不预测、不替用户决定、不提问；不需要再写「位置·牌名：」开头（这是追问，不是第一轮）。

### 多轮反馈（task = feedback，动作 REVISE / ACK）
看 `action_reason`：
- `REVISE`（用户不认同）：先坦然接受，不辩解、不坚持，收回那个具体说法；再从牌面给一个不同的读法，或请用户说说哪里不贴合（最多一个问题）。不说「其实你就是……」。60～140 字。
- `ACK:agree`：简短回应，不夸大牌的准确（不说「牌很准」「被我说中了」），把话交回用户，不提问。40～100 字。
- `ACK:unsure` / `ACK:nofeel`：说这很正常，没有共鸣也没关系，可以先放着；或给一个很轻的不同角度，不强求。最多一个问题。40～100 字。
- `ACK:addinfo`：只把补充的信息和已经说过的牌义轻轻连起来，不下结论、不扩大成判断。最多一个问题，而且只问用户想把注意力放在哪里（如「你最想先理清的是哪一部分？」），不追问私事细节。60～120 字。
- `ACK:discomfort`：先放慢，承认刚才的话可能说重了；不再继续解读，请用户选：继续、换个轻一点的方式，还是先停下（只问这一个问题）。40～90 字。
- `ACK:other`：依据已经说过的牌义简短回应，不预测、不替用户决定。用户问「接下来该做什么 / 是好是坏」时，不给指令、不判好坏，把牌里能借用的那一点说出来，交回用户。最多一个问题。40～120 字。
- `REVISE` 时用户没说哪一句不对：收回上一轮里最「替用户下判断」的那一句，或者直接请用户指出哪里不像。

## 新的反面回答类型
- `source_confusion`：把出处说错（把元素 / 星座对应说成「韦特原典」，或把现代解读说成原典）
- `absolute_claim`：把一个观点说成绝对真理，不讲适用条件
- `adds_content`：压缩时加了原文没有的内容
- `repeat_previous`：展开时基本重复上一轮的句子
- `insist_after_denial`：用户不认同后仍坚持原来的说法，或反过来说「其实你就是……」
其余类型（prediction、preachy、symbol_error、blame_user、over_questioning、presume_feelings ……）同前。反面要通顺、长度与正面相近、只明显犯指定的那一种错误。

## 自检
行数与 case_id 一一对应；字数在区间里；问号规则（EXPLAIN / PARABLE / WHISPER / COMPRESS / EXPAND 无问号；REVISE / ACK 最多一个；ACK:discomfort 恰好一个）；低语、压缩只有一句；error_type 等于 want_rejected。可以直接调用仓库里 `ai/corpus/check.py` 的 `check()` 自检（只读）。最后只回复一行：输出路径、条数、反面条数。
