# AI 训练计划：按 v0.6 原计划补齐语料（第三版）

决定（2026-11-28）：按 `tarot_slm_technical_design_v0.6.md` 第 13 章的原计划补齐**核心 2 万条**监督语料，十类全做，包括运行时还没用上的五类（哲学命题、微言大意、寓言隐喻、渐进展开、多轮反馈）。
原则：**先让运行时支持新任务，再写语料**（语料的输入必须是运行时真实发给模型的格式）；每类先小批试写、审查、定写法，再批量生产；数据全部备齐后**只训练一次**，用事先定好的标准验收。

## 一、十类语料的定义与配额

| 核心任务 | 配额 | 运行时动作（新 = 要新增） | 内容 |
|---|---:|---|---|
| 基础知识 | 2000 | ANSWER_MEANING、**EXPLAIN**（新） | 只要牌义（600）；知识问答（1400）：某个意象代表什么、元素 / 星象 / 希伯来字母对应、数字、韦特原典怎么说、两张牌的区别 |
| 符号抽象 | 2000 | ANSWER、EXPLAIN | 无提问的纯符号解读（单张、每日一牌、大牌阵）；从具体意象抽象到概念（狮子 → 本能与驯服） |
| 哲学命题 | 2500 | **EXPLAIN**（新） | 围绕已审核的命题与矛盾作解释：适用条件、反例、两种框架的不同读法；不宣称真理 |
| 微言大意 | 2500 | **WHISPER**（新） | 生成低语（1500，一句、≤24 字、有意象依据）；把一段解读压缩成一句（1000） |
| 寓言隐喻 | 2000 | **PARABLE**（新） | 借牌面意象讲 100～200 字的小寓言或比喻；不贴标签、不在结尾说教 |
| 多牌组合 | 2500 | ANSWER / 逐张生成 | 三张、镜像、五张、马蹄、凯尔特十字、两难、共鸣（现有 471） |
| 情境映射 | 2000 | ANSWER | 带问题的解读、问他人、诱导预测、自我类、反事实（「如果是逆位呢」）（现有 181） |
| 追问 | 1500 | ASK | 单张 / 三张 / 大牌阵的决策类，结尾一个开放问题（现有 108） |
| 渐进展开 | 1500 | **EXPAND**（新，多轮） | 上一轮解读之后，用户说「再说说 / 说具体点 / 换个角度 / 说短一点」：按 L0 关键词 → L1 微言 → L2 意象 → L3 哲学 → L4 情境 的层级展开，不重复上一轮 |
| 多轮反馈 | 1500 | **REVISE / ACK**（新，多轮），CLOSE | 用户否认（撤回假设、给替代解释）、补充信息、不确定、没有新认识、认可、不适或想结束 |
| **合计** | **20000** | | 现有 814 条计入相应类别 |

核心之外：个人联想（REFLECT）、玩梗（PLAYFUL_REPLY）各补到约 300 条。偏好对照（DPO）按约一成配：约 2000 对，覆盖已有十一种错误类型，另加「用户否认后仍坚持」「展开时重复上一轮」「寓言结尾说教」三种。

**22 张牌撑 2 万条的风险**：平均每张牌约 900 条，最容易出现的是句式重复。对策：
- 每类建大问题库（新写 1000+ 种问法，覆盖工作、学业、关系、家庭、自我、健康、钱、日常琐事）；
- 每张牌轮换引用不同意象；
- 脚本检查同牌回答之间的重复片段，超阈值的重写；
- 留出测试集的问法永不进训练。

## 二、阶段与验收

### 阶段 1：运行时支持新任务（不写语料）
- `policy.py`：新增 EXPLAIN（「代表什么 / 象征 / 怎么理解 / 对应什么」）、PARABLE（「讲个故事 / 打个比方」）、EXPAND（「再说说 / 展开 / 具体点 / 换个角度 / 短一点」）、反馈类（否认 / 补充 / 认可 / 没感觉）的路由；WHISPER 由程序按场景调用（仪式、收尾）。
- `engine.py`：多轮对话（保留上一轮回答）；各新动作的提示词与写法要求；EXPLAIN 的提示词带入知识库（意象、韦特原典要点、对应关系、命题与反例、矛盾）。
- 训练笔记本：多轮对话的渲染与本机 Ollama **逐字一致**（用同样的贪心解码方法验证）。
- 行为测试集回归 16/16；留出测试集补新任务的题（约 40 条），作为之后的尺子。

### 阶段 2：新任务小批试写（每类 40 条）
五个新任务各 40 条：写作 → 自动检查 → 语义审查 → 调整写作说明。写法定下来才进入批量生产。

### 阶段 3：分批生产到配额
按类别分波：每波若干子代理并行写，跑自动检查（格式、边界、编画面、重复片段），再做语义审查。
- 高风险类（多轮反馈、问他人、诱导预测、自我类）全量审查；
- 其余抽查 20%，抽查不合格率 > 5% 的整波返工。

每波结束更新下面的进度表并提交。

### 阶段 4：一次训练、验收
- **算力**：2 万条在单张 T4 上一轮约 5 小时，会超过 Kaggle 单次会话的 12 小时上限。笔记本改成双卡 T4 并行训练（约快一倍），加断点续训（每半轮存一次）。计划 2 轮监督训练，接着做偏好训练，一次会话内出两个候选（v3-sft、v3-dpo）。
- **验收**（训练前定死）：
  1. 原留出测试集规则通过率 ≥ 93%，且每类 ≥ 80%；
  2. 新任务留出题 ≥ 85%；
  3. 行为测试集连续 3 轮 16/16；
  4. 整句重复率 ≤ 2%；
  5. 盲评对第二版：分出胜负的组里胜率 ≥ 60%，且没有任何类别输。

  达不到就停下来分析，不立刻再训。
- 推理参数（重复惩罚等）在阶段 1 用第二版定下，之后统一使用。

## 四、规模与成本（如实估计）
- 新写约 19,000 条监督样例和约 1,650 对偏好对照，按目前子代理的写作速度，需要约 250 次写作任务加约 80 次审查任务，跨多次会话完成，数据准备合计约 3～4 个工作日。
- Kaggle：双卡约 6～8 小时一次（本周额度 30 小时，已用约 2.5 小时）。
- 已有的第二版（`naiwa-sft2:1.7b`）留作对照基线。
