## 阶段

### 0 · 地基整理 ✅
- [x] 牌、牌义外置为 `data/cards.json`，统一 ID（`major_00`…），旧本地记录自动迁移
- [x] 牌阵配置驱动：`data/spreads.json` 记录位置坐标、名称与含义；十字牌阵改为设计稿版
- [x] `npm run check` 数据校验（ID、中英文字段、牌面图片、光效引用、牌阵格位），构建前自动运行
- [x] 洗牌时锁定牌序与朝向；逆位概率默认 40%，设置里 0～100% 可调（今日一签按设备与日期固定，属于特例）
- [x] 牌全部落位后记入 sessionStorage，刷新页面原样恢复；重新抽牌时清除
- [x] 文案审校：「命运揭晓」等改为探索 / 翻牌语气，「命运十字」改名「十字指引」，解读面板加入「象征与反思、非预测」说明

### 1 · 原型神殿 + 天体仪（设计稿 V1）
- `archetypes.json`：22 个原创原型（名称、核心动力、光明面、阴影面、不足 / 适度 / 过度 / 受阻）
- 原型神殿：中心牌面，外环 天体 / 神话 / 心理 / 哲学 / 科学 / 符号，光影面与表达状态滑杆；图鉴升级为入口
- 天体仪（SVG）：12 星座 / 7 行星 / 3 元素三环，点击高亮对应大牌并进入神殿
- 翻牌后「开启神秘之门」过渡（可跳过、支持减少动效）

### 2 · 牌阵扩展
- 三牌阵语义变体（问题解析、身心灵、决策探索…）
- 马蹄（7）、凯尔特十字（10）、原创牌阵（命运之镜、命运岔路、灵魂共鸣）
- 手机端 10～12 张的布局方案
- 模板化解读：单牌 → 相邻关系 → 整体主题 → 开放式反思问题

### 3 · 扩展到 78 张（设计稿 V2）
- 56 张小牌美术（ChatGPT 工作流）、中英牌义、原型、36 个黄道区间
- 选牌交互重做（双层扇形 / 牌河）
- 包体约增加 25～30MB：考虑「仅大阿卡纳 / 完整 78 张」牌组选项；B 站 Toy 包上限 50MB

### 4 · 知识图谱（设计稿 V3）
- 节点与边带类别（传统对应 / 原创类比 / 事实知识）、来源与审核状态
- SVG 径向图：重新定心、关系筛选、返回路径

### 5 · 个人手记（设计稿 V5）
- IndexedDB：保存问题、牌阵、感想与回放；导出 / 删除；默认不上传
- B 站版云存档单条 ≤1KB，只同步图鉴、连续天数等轻量数据

### 之后
- 三维星图与真实天文视图（V4）
- AI 叙事（V6，需要后端，密钥不进前端）

## 已定事项（2026-11-24）

- 顺序：第 0 阶段 → **先广度（扩到 78 张）** → 原型神殿 + 天体仪 → 牌阵扩展 → 知识图谱 → 个人手记
- 十字牌阵：设计稿版（中心现状 / 左阻碍 / 右助力 / 上建议 / 下可能的发展）
- 逆位概率：默认 40%，可调
- 牌名：沿用站内「皇后 / 隐者」

## 待决事项
