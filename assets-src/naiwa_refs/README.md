# 奶蛙形象与体态参考图

用途：以后生成新牌面、新立绘或玩梗表情时，用来找相似的动作和比例。总览图是 [`overview.jpg`](overview.jpg)。

来源：
- 带 `mature-` / `juvenile-` / `expression-` / `variants` / `milk-egg-` 前缀的图，来自 [奶蛙百科 · 第 6 节「形象与体态」](https://neta.art/app/milk-frog-wiki)（Neta 平台，2026-11-27 保存）。**它们是第三方二创图，只作内部参考，不要直接放进网站或发布物料。**
- `egg/naidan-reference.png` 是用户提供的**奶蛋标准参考**。
- 其他图（`naiwa_character_reference.png`、`naiwa_juvenile_turnaround.jpg`、`card-back-egg.png`）是本项目自己的素材。

## 三种形态

| 形态 | 叫法 | 特征 | 本项目的用处 |
|---|---|---|---|
| 成熟态 | **奶蛙**（官网编号 No.00） | 梨形高个子，没有脖子；奶油色大肚皮；手脚修长，末端深橄榄褐色；凸出的绿眼睛，一字嘴 | **78 张牌面的主角**，出图身份基准是 `../naiwa_character_reference.png` |
| 幼态 | **小奶蛙**（奶蛙幼体；官网编号 No.01） | 头身比更大，身体更短更圆，四肢很短，眼睛占脸的比例更高，像一颗会笑的豆；有小圆球尾巴 | 还没有用到；适合童话、田园、静物或彩蛋场景 |
| 蛋形态 | **奶蛋**（官网编号 No.02） | 竖立的蛋形身体，下宽上窄，暖橙黄色，哑光质感；两只凸出的绿眼睛分得很开，位置偏上；中间是一道浅米色、略微上翘的小嘴，有一点立体感，像微笑；**没有手脚，没有尾巴** | **牌背中央的徽章**；Toy 图标也从这里取材。身份基准是 `egg/naidan-reference.png` |

注意：`../naiwa_juvenile_turnaround.jpg`（原来叫 `naidan_turnaround.jpg`）上印的字是「奶蛋」，但画的其实是**有手脚的幼体**。按上表，它归为「小奶蛙」（奶蛙幼体）。

另外，项目自己的奶蛙三视图比 Neta 的成熟态更圆、更胖，整体是同一种黄色，肚皮的颜色区分不明显。出牌面时以项目三视图为准，Neta 的图只借动作。

## 用法

1. 每次出图时，身份参考依然上传 `../naiwa_character_reference.png`。如果画的是幼体，换成 `../naiwa_juvenile_turnaround.jpg`；如果是奶蛋，换成 `egg/naidan-reference.png`。
2. 需要某个动作时，再把对应的动作图一起上传，并在提示里写明「只参考它的姿势，不改变奶蛙的比例和配色」。
3. 本项目的奶蛙默认**面无表情**。狂笑类动作只在玩梗模式或彩蛋里使用。
